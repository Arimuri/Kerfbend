SOURCE / FM SINE

FMフレーズを生成

ピュアなサイン波のフレーズを合成。FMの強さを上げると倍音が加わります。素材に追加するとチョップされます。

「生成・試聴」で元のフレーズを確認できます。
HOW TO / Kerfbend

使い方

  1. 音源の追加音源をドロップ。ファイル名にキーがあれば採用し、なければ音声を解析します。
  2. キー同期KEY SYNCは最初からON。合わせ先は自動選択か手動指定。素材ごとのキーも修正・補正解除できます。
  3. フレーズの生成再生しながらスライダーを調整。「新しいフレーズ」で別の組み合わせに。フレーズは1小節ずつ「A → Aの語尾だけ変更 → B → A」の形に並びます。breaksは小節の終わりの「呼吸」で、0なら途切れないループ。上げると4小節ごと（短いループは最後）にフィル（ドラムは16分のロール、主役は刻み、ベースと合いの手は休み）と、2小節の区切りで終わる全パート共通の休符が入り、次の小節の頭で最初の音に着地します。
  4. レーン操作LOCKで断片と配置を固定。Mはミュート、Sはソロ。↶で前の状態に戻せます。
  5. WAVの書き出し「WAVを書き出す」でループを保存します。
「＋ FM音源を生成」で、サイン波をFM変調したフレーズを作れます。現在のBPM・小節数で合成し、キー・オクターブ・音色・密度を指定できます。「生成・試聴」で元フレーズを確認し、「素材に追加してチョップ」でその他の素材に追加。「コード進行」は1小節ごとにコードを変えます（同じコード、2コード往復、王道進行、小室進行）。拍の頭はその小節のコードの音、拍の間は経過音になり、試聴画面に各小節のコード名を表示します。新しいFM音源はループ内の既存のFM音源と同じ進行が初期値になるため、ベースと上物で和音がそろいます。チョップ時は最初のFM音源の進行に合わせ、別の小節へ動かした音は、その小節のコードで同じ役割（ルート・3度・5度・経過音）の音に置き換え、ベースと小節頭の着地はルートを鳴らします。FM音源は均等分割ではなく音符の区切りで切り、1音〜数音のまとまりを元のリズムのまま並べ替えます。まとまりの長さはsizeで変わります（25%未満で1音、75%未満で1〜2音、それ以上で2〜3音）。「別のフレーズ」はSEEDを変更します。FMの強さは初期値0のピュアなサイン波で、上げるとFMの倍音が加わります。FM音源の音は1周期以上かけて立ち上がり、音の途中で切った断片は30 msかけて閉じるため、低いサイン波でもクリックしにくくなっています。追加後はキー同期や各エフェクトを適用でき、↶で追加を戻せます。

素材ごとに役割（主役・ベース・合いの手）があります。自動では名前（vocal・chop・lead / bass・808・subなど）やFM音源のオクターブ（1〜2）から主役とベースを1つずつ選び、ほかは合いの手になります。ベースは各小節の頭に必ず入り、音を長めに保ち、上方向のオクターブ移動をしません。合いの手は主役が鳴っている間は控えめに、主役の休みに多く鳴ります。各素材の「役割」で変更でき、変更すると同じSEEDで作り直します（LOCK中のレーンは保持）。ドラムの素材はドラムの役割です。

素材は「その他」と「ドラム」に分けて表示します。kick・snare・drumsなどのファイル名はドラムに自動分類し、各素材の「分類」で変更できます。分類を変えても素材のキー設定は保持します。

octaveは±1オクターブ移動の確率です。0%で移動なし、100%ですべての断片が上下どちらかに移動します（下1：上3）。motionは逆再生を調整します。LOCK中のレーンは元の音程・逆再生を保持します。

PITCH ENVは断片の頭で上下ランダムにピッチを振り、元のピッチへ戻します。振れ幅は0〜24半音（0でOFF）、戻る時間は5〜500 ms。「幅のばらつき」は断片ごとの振れ幅を1半音〜設定値の間で半音単位に、「速さのばらつき」は戻る時間を最大1/4〜4倍の間で変えます（長くなる場合も断片の7割までに戻ります）。「パートごとの発生確率」では素材ごとに、かかる断片の割合を0〜100%で指定します。確率を上げても、すでにかかっている断片はそのままです。同じ断片では方向・幅・時間を保持し、LOCK中にも反映します。短い断片では戻り切る前に音が終わる場合があります。

同時発音数は「その他」「ドラム」それぞれ1〜8個で指定します。例えば両方1個なら、その他1音とドラム1音が同時に鳴ります。上限を超える断片は省略し、素材と元の配置は保持します。上限を戻すと省略した断片も戻ります。LOCK中もこの上限を適用します。

素材は最大16個、1ファイル40 MB・120秒以内、合計240秒以内。読み込める形式はブラウザにより異なります。

キー名はC#m・Bb minor・F major・Camelotの8Aなどに対応。音声解析は推定で、判定が曖昧な音や打楽器は自動移調を保留します。誤判定は各素材のメニューで修正できます。自動の合わせ先は、キーが分かるユーザー素材をデモより優先します。

すべての音程付き素材をメジャーキー基準で扱います。マイナーは平行調に読み替えます（A minor → C major、D minor → F major）。読み替え自体では音程を変えず、読み替え後のキーから合わせ先に移調します。単音や長短不明のルートは、同じルートのmajorを処理上の基準にします。元の判定は素材欄で確認・修正できます。和音そのものの長短調は変換しません。LOCK中もキー同期は反映されます。ピッチ変更に伴って再生速度も変わり、独立したタイムストレッチは未実装です。

音源と編集状態はページを閉じると失われるため、保存する場合はWAVを書き出してください。MONITORは試聴専用で、WAVの音量には影響しません。
