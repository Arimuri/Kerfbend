# 公開用ソースの作成

配布コードに含める第三者の実装・数値表・利用条件は [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) に記載しています。画面からは [ライセンス・出典](../licenses.html) を開けます。FFTにはfft.js 4.0.4を使用し、公式ソースの固定コミット、SHA-256、ブラウザ用ラッパーの変更範囲を [provenance.json](../vendor/fft.js/provenance.json) に記録しています。

## 配布ファイルの確認

```sh
python3 scripts/verify_vendor.py
```

ネットワークを使わず、同梱したFFT本体が記録した上流ソースのハッシュと一致すること、MIT通知の全文、PartituraのApache-2.0原文、出典文書の存在を検証します。ブラウザの `tests/index.html` からFFT・キー解析・音声処理のテストも実行できます。

第三者表示・ライセンスファイルと `vendor/` を配布に含めてください。ブラウザ用FFTファイルにもMIT全文を収録しています。圧縮・バンドル化する場合も、著作権表示と許諾文を保持してください。

## 公開用ZIP

変更をコミットした後、次のコマンドで現在のソースだけを取り出せます。

```sh
python3 scripts/export_source.py
```

出力は `exports/kerfbend-source.zip` です。内容は `git archive HEAD` による最新コミットのファイルで、`.git/`、未追跡ファイル、ローカルIDE設定、読み込んだ音源は含みません。

ZIPはGit履歴を含めずにソースを配布する場合に利用してください。アーカイブ作成スクリプトはGitHubへの作成・送信・公開を行いません。ZIPは作成時点のスナップショットなので、変更後に配布する場合は再作成してください。
